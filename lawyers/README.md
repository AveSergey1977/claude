# Карта юристов — выгрузка контактов

Источник: https://gulenkovalegal.ru/lawyers (каталог хранится на странице в виде JSON в блоках `<script data-km-catalog="1">`).

| Файл | Назначение |
|---|---|
| `scrape_lawyers.py` | Скачивает страницу, проверяет целостность блоков данных и пишет `lawyers.xlsx`. |
| `lawyers.xlsx` | Первый лист `ГГГГММДД` — первичная выгрузка. Новый лист `ГГГГММДД` добавляется только при изменениях: полный текущий список со статусом строки (новый / изменён / без изменений) и строки, исчезнувшие с сайта (удалён). Последний лист `Журнал` — каждая проверка, включая проверки без изменений и ошибки. |

Записи сопоставляются по паре «город + ФИО». Один человек, указанный в нескольких городах, даёт несколько строк — так на сайте.

Проверка запускается ежедневно в 22:00 по Вильнюсу (Europe/Vilnius) запланированной задачей Claude Code; результат коммитится в эту ветку.

```sh
pip install openpyxl
python3 lawyers/scrape_lawyers.py --out lawyers/lawyers.xlsx
```
