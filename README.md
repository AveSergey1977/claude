# Портфель: котировки

Статическая страница с котировками GOOG, AAPL, NVDA, MO, VUSA.L, UDVD.L, полем количества по каждой бумаге, стоимостью позиций и итогом портфеля в USD.

## Как устроено

| Компонент | Файл | Назначение |
|---|---|---|
| Страница | `site/index.html` | Таблица котировок, ввод количества, итоги в USD. Количество хранится в `localStorage` браузера и на сервер не передаётся. Данные перечитываются каждые 5 минут и при возврате на вкладку. |
| Сборщик | `scripts/fetch_quotes.py` | Получает котировки и курс GBP/USD из Yahoo Finance (резерв для курса — ECB через Frankfurter), пишет `site/data/quotes.json`. Котировки в пенсах (GBp) приводятся к GBP. Если бумагу получить не удалось, остаётся последняя цена с пометкой «устар.». |
| Расписание | `.github/workflows/quotes.yml` | GitHub Actions: каждые 15 минут, пока открыта LSE (08:00–16:30 Лондон) или NYSE (09:30–16:00 Нью-Йорк), плюс 20 минут после закрытия; в остальное время — каждые 6 часов (00/06/12/18 UTC). Результат публикуется на GitHub Pages. |

## Запуск

1. Слить ветку в `main` (расписание GitHub Actions работает только в ветке по умолчанию).
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Actions → Quotes → **Run workflow** — первый запуск создаёт `data/quotes.json` и публикует страницу.
4. Адрес страницы: `https://<owner>.github.io/<repo>/` (виден в Settings → Pages и в выводе шага deploy).

## Ограничения

- GitHub Pages для приватного репозитория доступен только на платных планах GitHub (Pro/Team/Enterprise); на Free репозиторий нужно сделать публичным. Опубликованная страница в любом случае общедоступна по ссылке (количество бумаг в неё не попадает).
- Для приватного репозитория на Free расход ≈ 1 400 минут Actions в месяц из 2 000 бесплатных; для публичного — бесплатно.
- Праздничные дни бирж не учитываются; запуски по расписанию GitHub могут задерживаться.
- Yahoo Finance — неофициальный API без SLA; при изменении формата ответа сборщик упадёт, а страница покажет последние данные с предупреждением.

## Локальная проверка

```sh
python3 scripts/fetch_quotes.py fetch --out site/data/quotes.json
python3 -m http.server -d site 8000
```
